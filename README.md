# FA Calculator

First Advantage Date & Standard Calculator (PWA for GitHub Pages).

## Quick Setup on GitHub Pages:
1. Create a new repository on GitHub (e.g., `fa-calculator`).
2. Upload all files from this folder (`index.html`, `manifest.json`, `sw.js`, and the `icons/` folder).
3. Go to **Settings** > **Pages** in your repository.
4. Under **Branch**, select `main` (or `master`) and click **Save**.
5. Your live link will be: `https://<your-username>.github.io/fa-calculator/`

When opened in Chrome, Edge, or Brave, the browser will automatically show the native **Install** icon in the address bar!
